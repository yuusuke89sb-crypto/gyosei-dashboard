👆 1. 基本操作

要素の選択・移動

  1. 左サイドバーの「👆 選択 / 移動」ボタンをクリック（または Esc で選択モードに切替）
  2. キャンバス上の要素をクリックすると選択状態になり、プロパティパネル（調整バー）が表示されます
  3. 選択した要素をドラッグすると自由に移動できます
  4. 選択解除するには、何もない場所をクリックします

要素の回転

選択状態の要素は、プロパティパネルの回転スライダーまたはボタンで回転できます。R キーで +5° ずつ、Shift+R で -5° ずつ回転します。

要素のサイズ変更

プロパティパネルの「➖ 縮小」「➕ 拡大」ボタンで要素サイズを調整できます。

要素の削除

選択した状態で Delete キー、または「🧹 要素削除」ツールで不要な要素をクリックして削除できます。

元に戻す / やり直し

Ctrl+Z で元に戻す、Ctrl+Y でやり直しができます。

📐 3. Jw_cadライク機能 Jw_cad

建築CAD「Jw_cad」の主要操作に対応した機能を搭載しています。

🧲 吸着スナップ（Sキーで切替）

端点・交点・中点・角に自動的にピタッと吸い付きます。線を引く時やドラッグ移動時にスナップポイントが自動検出され、線の始点や終点が既存の線と正確に一致します。

💡 スナップポイント表示:
■ 緑の四角 = 端点・角
△ 水色の三角 = 中点
× オレンジのクロス = 交点

📏 線の伸縮（端点ドラッグ）

選択した線の両端に表示される丸ハンドル（○）をドラッグすることで、自由に線の長さを変更できます。スナップも効くので、他の線の端点にピッタリ合わせられます。

🪜 複線（Fキー）

  1. 「🪜 複線 (平行線)」ボタンをクリック、または F キーを押す
  2. 基準にする線をクリック
  3. プロパティバーで間隔（メートル単位）を設定
  4. 平行線を作りたい側（左右/上下）をクリック → 指定距離で完全な平行線が生成！
💡 「両側複線」ボタンで左右両側に一括生成も可能（道路の両端作成に便利）

📐 コーナー結合

  1. 「📐 コーナー結合」ボタンをクリック
  2. 1本目の線をクリック
  3. 2本目の線をクリック → 2本の線が交点で隙間なく綺麗に結合されます

📐 直交ロック（Shiftキー / Oキー）

線を引く際に Shift を押しながらドラッグ、または O キーで常時直交ロックをON/OFFできます。水平・垂直方向にのみ線が引けるようになります。

📋 複写（Ctrl+C / Ctrl+V / Ctrl+D）

選択した要素を Ctrl+C でコピー → Ctrl+V で貼り付け。Ctrl+D で即座に複製（少しずらして配置）もできます。

✂️ T字路・交差点成形

「✂️ T字路・交差点成形」ボタンをクリックすると、交差している道路線の接続部分を自動検出し、道路として綺麗に開口（T字路のように成形）します。

🆕 4. 新機能 NEW

📐 CAD寸法線

2点をドラッグすると、プロのCAD図面と同じ引き出し線＋矢印＋実寸メートル値を自動生成します。スナップ対応で正確な寸法計測が可能です。

  1. 「📐 CAD寸法線」ツールを選択
  2. 計測したい始点をクリック → 終点までドラッグ
  3. 自動で実寸値（m）が算出されます。プロパティパネルで数値の手動編集も可能

- - 破線（屋根・庇）

カーポートの屋根、庇、上空の障害物など、地面に設置されていない構造物を破線で表現できます。

─・─ 敷地境界（一点鎖線）

敷地の境界線、官民境界線、道路の中心線を一点鎖線で表現できます。正式な配置図での区分線に使用します。

線種の変更

既存の直線や道路線を選択して、プロパティパネルの「線種」ボタンで実線 → 破線 → 一点鎖線に変更できます。

📋 アレイ複写（等間隔複製＋自動連番）

選択した要素を指定方向（上下左右）に指定間隔でN個一括コピーできます。駐車場の枠を一発で量産できる便利機能です。

  1. 複写したい要素を選択（例：保管場所の枠）
  2. プロパティパネルの「📋 アレイ複写」ボタンをクリック、または A キーを押す
  3. 個数（例：5）→ 方向（right/left/up/down）→ 間隔（px）を入力
  4. 保管場所枠の場合、自動で①②③…の連番が付与されます
💡 月極駐車場の6台・10台の枠をワンクリックで一括配置できます！

🗑️ 5. 消去機能

🧹 要素削除（単体）

「🧹 要素削除」ツールで、クリックした要素を1つずつ削除します。選択モードで Delete キーでも削除可能です。

🟥 範囲消去

「🟥 範囲消去」ツールで矩形をドラッグすると、範囲内に中心がある全ての要素を一括削除します。大量のオブジェクトを一度にクリアしたい時に便利です。

✂️ 節間消去

交差している線の飛び出した部分だけを消去します。交差点からはみ出した不要な線端を綺麗にトリミングできます。

  1. 「✂️ 節間消去」ツールを選択（または E キー）
  2. 消去したい線の「飛び出し部分」付近をクリック
  3. クリック位置を挟む交差点間のセグメントが消去されます

✂️ T字路・交差点成形（自動）

「✂️ T字路・交差点成形」ボタンで、全ての道路線の交差部分を自動検出し、T字路や交差点の開口を一括成形します。

❓ 9. よくある質問 (FAQ)

▶ 線をピッタリ端点に合わせるにはどうすればいい？
「🧲 吸着スナップ」がONの状態（Sキーで切替）で線を引くと、既存の端点・交点・中点に自動的にスナップします。端点に近づくと緑の四角マーカーが表示されます。
▶ 道路の幅を指定して平行線を引きたい
①基準線を描画 → ②Fキーで複線ツールを起動 → ③間隔（メートル）を入力 → ④クリック側に平行線が生成されます。「両側複線」で左右同時生成も可能です。
▶ 駐車場の枠を一括で量産したい
①1つ目の枠を作成 → ②選択して Aキーまたは「📋 アレイ複写」ボタン → ③個数・方向・間隔を入力で一括複製。保管場所枠の場合は自動で①②③…の連番が付きます。
▶ カーポートの屋根部分はどう表現する？
「- - 破線（屋根・庇）」ツールで破線を描画してください。配置図では、地面に設置されていない上空の構造物は破線で表現するのが一般的です。
▶ 敷地の境界線を描きたい
「─・─ 敷地境界(鎖線)」ツールで一点鎖線を描画するか、通常の直線を描いた後にプロパティパネルで線種を変更できます。
▶ 交差点部分の線が重なってしまう
「✂️ T字路・交差点成形」ボタンで自動成形するか、「✂️ 節間消去」ツール（Eキー）で飛び出し部分だけをクリックして消去してください。
▶ データが消えてしまった！
作図データは自動的にlocalStorageに下書き保存されています。「📜 履歴・下書き復元」ボタンから復元できる場合があります。大切なデータは「💾 JSON保存」で手動バックアップを推奨します。
