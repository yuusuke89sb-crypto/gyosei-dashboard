# Google スプレッドシート セットアップガイド

## 📋 手順

### ステップ 1: スプレッドシートの新規作成

1. [Google スプレッドシート](https://sheets.google.com) を開く
2. **「空白のスプレッドシート」** をクリック
3. ファイル名を **「行政書士事務所_マスタ管理」** に変更

---

### ステップ 2: Apps Script の設定

1. メニューバーの **「拡張機能」→「Apps Script」** をクリック
2. エディタが開いたら、既存のコード（`function myFunction() {}` 等）を **全て削除**
3. `gas/master_sheets.gs` の内容を **全てコピー＆ペースト**
4. **💾 Ctrl + S** で保存（プロジェクト名は任意）
5. Apps Script のタブを閉じてスプレッドシートに戻る

---

### ステップ 3: 初期セットアップの実行

1. スプレッドシートの **ページを再読み込み**（F5キー）
2. メニューバーに **「🔧 マスタ管理」** が表示される
3. **「🔧 マスタ管理」→「🚀 初期セットアップ」** をクリック
4. 初回のみ **「承認が必要です」** と表示される → **「権限を確認」→ アカウント選択 → 「許可」**
5. 確認ダイアログで **「はい」** をクリック
6. 完了メッセージが表示されれば成功 ✅

> 以下3つのシートが自動作成されます：
> - **顧客マスタ** — 顧客情報の管理（ID 自動採番）
> - **担当者マスタ** — 事務所スタッフの管理（ID 自動採番）
> - **操作ログ** — 変更履歴の自動記録

---

### ステップ 4: 🔒 セキュリティ設定（重要）

#### 共有設定の制限

1. 右上の **「共有」** ボタンをクリック
2. **「一般的なアクセス」** を確認
3. ⚠️ **「リンクを知っている全員」になっている場合は危険！**
4. **「制限付き」** に変更（特定のユーザーのみアクセス可能）
5. 必要なメンバーのみメールアドレスで招待

#### 推奨アクセス権限

| ユーザー | 権限 |
|---|---|
| 代表（自分） | オーナー |
| 補助者・事務員 | 編集者 |
| 外部関係者 | **共有しない**（原則） |

#### ダウンロード制限（推奨）

1. **「共有」→ 歯車アイコン ⚙️** をクリック
2. **「コメント権限者と閲覧権限者のダウンロード、印刷、コピーを無効にします」** にチェック ✅

---

## 🔧 日常の使い方

### データ入力

1. 顧客マスタの **2行目以降** に氏名等を入力
2. **顧客 ID・登録日・更新日** は自動入力されます
3. 区分（個人/法人）やステータスは **ドロップダウン** から選択

### データ検証

メニュー **「🔧 マスタ管理」→「✅ データ検証」** で以下をチェック：
- 氏名の空欄
- 電話番号の形式（10〜11桁の数字）
- メールアドレスの形式
- 郵便番号の形式（7桁）

### 操作ログの確認

**「操作ログ」シート** に全ての変更が自動記録されます：
- 日時、操作者のメールアドレス、変更内容

## 🔗 ダッシュボードとの連携

### ステップ A: GAS を Web App としてデプロイ

1. **拡張機能 → Apps Script** を開く
2. 右上の **「デプロイ」→「新しいデプロイ」** をクリック
3. 歯車アイコン → **「ウェブアプリ」** を選択
4. 設定:
   - **説明**: マスタ連携API
   - **次のユーザーとして実行**: 自分
   - **アクセスできるユーザー**: ⚠️ **「自分のみ」** を推奨
5. **「デプロイ」** をクリック
6. 表示された **URL をコピー**（`https://script.google.com/macros/s/xxx/exec` 形式）

> ⚠️ **セキュリティ注意**: 「全員」に設定すると、URLを知っている人は誰でもデータにアクセスできます。

### ステップ B: ダッシュボードに URL を設定

1. ダッシュボード（`index.html`）をブラウザで開く
2. サイドバーの **「⚙️ 設定」** をクリック
3. コピーした GAS URL を貼り付け
4. **「🔍 接続テスト」** で接続を確認
5. **「💾 保存」** をクリック

### ステップ C: データの同期

- **手動同期**: サイドバーの **「🔄 同期」** ボタンをクリック
- **自動同期**: ページを開くたびに自動でスプレッドシートのデータを取得
- **双方向連携**: ダッシュボードで顧客を追加・編集すると、スプレッドシートにも自動反映
