## 概要

行政書士事務所向けのオールインワン業務管理ダッシュボードです。ブラウザだけで動作し、以下の業務を一元管理できます。

| 機能 | 説明 |
|------|------|
| 顧客管理 | 個人・法人の連絡先、紹介元、担当者割り当て |
| 案件管理 | カンバンボード形式で進捗管理、テンプレート自動適用 |
| スケジュール | 月間カレンダー、Googleカレンダー双方向同期 |
| 帳簿 | 複式簿記の仕訳帳、月次/年間レポート |
| 請求書 | A4印刷対応の請求書自動生成・PDF保存 |
| FAX | eFax連携による送受信管理 |
| データ同期 | Googleスプレッドシート経由の複数デバイス同期 |

### データの保存先

すべてのデータは **ブラウザの localStorage** に保存されます。スプレッドシート連携を設定すると、Googleスプレッドシートにもリアルタイムで同期されます。

## 起動・ログイン

### 起動方法

`index.html` をブラウザで開くだけで使用できます。サーバー不要。

### ログイン

- 初期パスワード: `gyosei2026`
- セッションタイムアウト: **30分**（無操作で自動ログアウト）
- 連続5回ミスで **3分間ロックアウト**

### パスワード変更

サイドバー下部の「🔑 PW変更」から、現在のパスワードを確認の上、新しいパスワード（4文字以上）に変更できます。

## 📊 ダッシュボード

起動直後に表示されるホーム画面です。

### 統計カード

| カード | 内容 |
|--------|------|
| 📋 進行中 | 完了以外の案件数 |
| 👥 顧客数 | 登録顧客の総数 |
| ⚠️ 期限間近 | 3日以内に期限を迎える案件数 |
| 💰 今月売上 | 今月完了した案件の報酬合計 |
| 💴 未入金 | 未入金の請求がある場合に表示 |

### クイックアクション

ダッシュボードから直接以下の操作ができます：

- 👤 **顧客追加** → 顧客登録フォームを即時表示
- 📋 **案件登録** → 案件登録フォームを即時表示
- 📅 **予定追加** → 予定登録フォームを即時表示
- 💹 **仕訳追加** → 仕訳入力フォームを即時表示

### セクション

- 📌 **今日の予定** — 本日の期限案件とスケジュール
- 🔥 **期限間近の案件** — 3日以内に期限がある案件（超過は赤表示）
- ⏰ **相続期限アラート** — 相続案件の法定期限（放棄3ヶ月、税申告10ヶ月等）
- 📅 **今後7日間の期限** — 4〜7日以内の目前案件
- 💰 **今月の収支** — 売上・経費・差引利益のサマリー
- 📊 **ステータス別/カテゴリ別** — 案件の分布グラフ

## 📋 案件管理

### 表示形式

| デバイス | 表示形式 |
|----------|----------|
| PC（768px以上） | **カンバンボード**（ドラッグ＆ドロップ対応） |
| モバイル | **リスト形式**（ステータスボタンで切替） |

### ステータス（進捗フロー）

```
📥 受付 → 🎤 ヒアリング → 📝 書類作成 → 📤 申請中 → ✅ 完了
```

- カンバンボードでカードをドラッグ＆ドロップしてステータス変更可能
- モバイルではボタンタップで簡単変更
- **完了時に報酬が設定されている場合**、仕訳（売掛金/売上高）が自動生成

### カテゴリ

現在の業務範囲に合わせ、以下の4つのカテゴリに限定して管理します：

| カテゴリ | アイコン |
|----------|----------|
| 車庫証明（OSS） | 🚗 |
| 車庫証明（紙） | 🚗 |
| 丁種封印 | 🚙 |
| 相続 | 📜 |

### 案件テンプレート

新規案件登録時、**カテゴリを選択すると自動的にテンプレートが適用**されます：

- **報酬額のデフォルト値**が入力される（例：車庫証明→¥8,000、相続→¥50,000）
- **チェックリスト付きメモ**が自動挿入される（必要書類・手順がプリセット）

### 添付書類とお預かり証・送付状

案件詳細の「📎 添付書類」パネルから以下の操作が可能です：

- **ファイルのアップロード**: PDF・画像などを登録（Googleドライブに自動連携）。
- **ドライブフォルダ構成**: `顧客名 / 案件書類 / {日付}_{案件ID}_{案件名}` の見やすいフォルダ階層で自動整理されます。
- **帳票の自動生成**:
  - **📥 お預かり証作成**: アップロード済みの書類リストが入ったお客様向けのお預かり証PDFを発行します。
  - **📤 送付状作成**: 納品時の書類一覧が記載された送付状（かがみ）PDFを発行します。
  - （※書類が0件の場合は、印刷して手書きで使える空欄のテンプレートが生成されます。）

### 書類チェックリスト

メモ内の `□` / `■` 記号がチェックリストとして表示されます。

- クリックで完了/未完了をトグル
- 進捗バーで完了率を可視化

### 車庫証明・丁種封印案件の特別機能

車関連のカテゴリ（車庫証明・丁種封印）を選択すると、以下の専用入力欄が出現します：

- **現地調査予定日**: 駐車場等の現地調査を行う予定日。
- **警察署交付（予定）日**: 警察署での書類や標章の受け取り予定日。
- **所轄警察署プルダウン**: ルート検索と連動した管轄警察署のリスト（愛知・岐阜対応）から選択可能。

> 💡 日付を入力すると、ダッシュボードの案件カード上に **「📍 調査: 10/20」** や **「🚔 交付: 10/25」** といったバッジが目立つように表示され、スケジュールが直感的に把握できます。

### 相続案件の特別機能

相続カテゴリの案件では以下が追加表示されます：

- **被相続人死亡日**の入力フィールド
- **⏰ 相続期限アラート**（法定期限を自動計算）

| 期限 | 起算日 | 期間 | 重要度 |
|------|--------|------|:------:|
| 相続放棄 | 知った日 | 3ヶ月 | 🔴 |
| 準確定申告 | 死亡日 | 4ヶ月 | 🟡 |
| 相続税申告・納付 | 死亡日 | 10ヶ月 | 🔴 |
| 遺留分侵害額請求 | 知った日 | 1年 | 🟡 |
| 相続登記義務化 | 知った日 | 3年 | 🟠 |

### フィルタリング

- **カテゴリフィルタ** — 特定の業務分野だけ表示
- **ステータスフィルタ** — 特定の進捗段階だけ表示
- 完了から7日以上経過した案件は自動的に非表示（「完了」フィルタで表示可能）

### 期限の色分け

| 色 | 条件 |
|----|------|
| 🔴 赤 | 期限超過 |
| 🟠 オレンジ | 3日以内 |
| 🟡 黄 | 7日以内 |

## 📅 スケジュール（カレンダー）

### 月間カレンダー

- 案件の期限と予定をまとめて表示
- 日付クリックで**日の詳細**モーダルを表示
- 空の日をクリックすると**予定追加**フォームが自動表示

### 予定の種別

| 種別 | 色 |
|------|-----|
| 🤝 打ち合わせ | 青 |
| 🚗 外出・訪問 | 紫 |
| 📚 研修・勉強 | 緑 |
| ⏰ 締切 | 赤 |
| 📌 その他 | 黄 |

### 予定の登録項目

タイトル（必須）、日付（必須）、種別、開始時刻、終了時刻、担当者、メモ

### 担当者フィルタ

カレンダー上部のプルダウンで特定の担当者だけの予定を絞り込み表示できます。

### 相続期限表示

「📜 相続期限」ボタンをクリックすると、すべての相続案件の法定期限がカレンダー上に表示されます（デフォルト非表示）。

### Googleカレンダー連携

- **🔄 Google同期** — Googleカレンダーの予定を取り込み
- 予定の追加・編集・削除がGoogleカレンダーに自動反映
- 取り込み済みの予定は重複しません

### iCalエクスポート

**📤 カレンダー出力** ボタンで `.ics` ファイルをダウンロードできます。
- 案件期限、予定、相続期限を含む
- 担当者フィルタ適用中はその担当者分のみ出力
- Apple Calendar、Outlook 等に直接インポート可能

### 今後の予定リスト

カレンダーの下に、直近の予定を時系列で表示します（案件・予定・相続期限を統合）。

## 💹 帳簿（会計）

### 仕訳帳

複式簿記形式の仕訳帳です。

| 項目 | 説明 |
|------|------|
| 日付 | 取引日 |
| 借方 | 費用・資産勘定 |
| 貸方 | 収入・負債勘定 |
| 金額 | 取引金額 |
| 摘要 | 取引の説明 |

### 勘定科目一覧

| 分類 | 勘定科目 |
|------|----------|
| 収入 | 売上高、雑収入 |
| 費用 | 旅費交通費、通信費、消耗品費、事務用品費、家賃地代、水道光熱費、接待交際費、広告宣伝費、支払手数料、租税公課、研修費、新聞図書費、保険料、減価償却費、雑費 |
| 資産 | 現金、普通預金、売掛金、事業主貸 |
| 負債 | 未払金、事業主借 |

### 自動仕訳生成

以下のアクションで仕訳が自動作成されます：

| トリガー | 借方 | 貸方 | 備考 |
|----------|------|------|------|
| 案件ステータスを「完了」に変更 | 売掛金 | 売上高 | 報酬額が設定されている場合のみ |
| 入金を確認 | 普通預金 | 売掛金 | 入金管理画面から |

自動生成の仕訳には「自動」バッジが表示されます。

### 月間集計

帳簿画面上部で年月を切り替えると、その月の収入・支出・収支がサマリー表示されます。

### CSV出力

「📥 CSV出力」ボタンで、表示中の月の仕訳データをCSVファイルとしてダウンロードできます（UTF-8 BOM付き、Excel互換）。

## 📠 FAX管理

eFax（メールFAX）との連携機能です。スプレッドシート連携の設定が必要です。

### FAX送信

1. 「📤 FAX送信」ボタンをクリック
2. FAX番号を入力
3. 必要に応じて件名・本文・PDF添付を設定
4. 「📠 送信」をクリック

### FAX受信

「📥 受信チェック」ボタンで、eFaxから届いた受信FAXをGoogleドライブに自動保存します。

### 送受信履歴

「🔄 履歴更新」ボタンで送受信の一覧を表示します。

## 🔧 拡張機能・ツール

### 🔍 グローバル検索（Ctrl+K）

顧客名・案件名をキーワード入力で横断検索します。検索結果をクリックすると該当画面に直接ジャンプします。

### 💴 入金管理

請求書発行と連動した入金追跡機能です。

- **全て / 未入金 / 入金済** のタブで絞り込み
- 「入金」ボタンで支払い確認（普通預金への振込として自動仕訳）
- 期限超過の請求は赤く警告表示

### 📊 年間収支レポート

年単位の月別収支を一覧表示します。

- 月別の収入・支出・利益テーブル
- 年間合計のサマリー
- **経費科目別内訳**（構成比%付き）
- 前年・翌年への切り替えも簡単

### 📄 月次レポート

月ごとの詳細レポートを表示します。

### 🔄 定型仕訳

毎月の固定費（家賃、通信費、保険料等）をワンクリックで一括登録できます。

- 定型仕訳のテンプレートを追加・編集・削除
- 登録済みの定型費用を**一括で仕訳に投入**
- 固定費ツールとの連携にも対応

### 🤝 紹介元分析

顧客の紹介元を集計し、どのルートから顧客を獲得しているかを分析します。

- 紹介元ごとの**顧客数**と**売上合計**
- グラフで紹介元比率を視覚化

### 📝 対応履歴

顧客・案件ごとに時系列の連絡/対応記録を残せます。

- テキスト入力で手軽に追記
- 最新10件を表示（古い履歴も保持）

### ⏰ 期限リマインダー

ブラウザ通知で期限間近の案件を自動通知します。

- 初回アクセス時に通知許可を要求
- 1日1回、3日以内に期限のある案件を通知

## 🔄 データ管理・バックアップ

### スプレッドシート同期

Googleスプレッドシートと双方向同期ができます。

- **設定方法:** サイドバーの「⚙️ 設定」→ GAS Web App URL を入力
- **自動同期:** 3分ごとに自動で最新データを取り込み（画面非表示時・モーダル操作中はスキップ）
- **手動同期:** サイドバーの「🔄 同期」ボタン
- **接続テスト:** 設定画面内の「🔍 接続テスト」で事前確認

### 同期対象データ

| データ | Pull（取り込み） | Push（送信） |
|--------|:-:|:-:|
| 顧客 | ✅ | ✅ |
| 担当者 | ✅ | — |
| 案件 | ✅ | ✅ |
| 帳簿 | ✅（マージ） | ✅ |
| 請求書PDF | — | ✅（Drive保存） |
| カレンダー | ✅ | ✅ |

### バックアップ・復元

- **💾 バックアップ:** 全データをJSONファイルとしてダウンロード
- **📂 復元:** JSONファイルを読み込んでデータを復元

> ⚠️ 復元は現在のデータを**完全に上書き**します。事前にバックアップを取ることを推奨します。

### バックアップに含まれるデータ

顧客、案件、担当者、予定、仕訳、入金、対応履歴、定型仕訳、目標、固定費、連携設定
