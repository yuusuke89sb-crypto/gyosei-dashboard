# 🔧 WordPress 修正手順ガイド

> 以下の6項目を上から順番に修正してください。全て WordPress 管理画面から操作できます。
> 合計所要時間：約15分

---

## ① 「Hello world!」記事を削除する

1. WordPress管理画面にログイン
2. 左メニュー → **「投稿」** → **「投稿一覧」**
3. 「Hello world!」にカーソルを合わせる
4. **「ゴミ箱へ移動」** をクリック
5. 完了 ✅

---

## ② サイドバーの「最近の投稿」「最近のコメント」を削除する

1. 左メニュー → **「外観」** → **「ウィジェット」**
2. 「サイドバー」または「フッター」にある以下を探す：
   - **「最近の投稿」ウィジェット** → 開いて **「削除」**
   - **「最近のコメント」ウィジェット** → 開いて **「削除」**
3. ブロックエディタの場合は、該当ブロックを選択 → 「⋮」メニュー → **「ブロックを削除」**
4. **「更新」** をクリック
5. 完了 ✅

> **注意：** テーマによっては「外観→カスタマイズ→ウィジェット」から操作する場合もあります。

---

## ③ プロフィール画像を設定する

現在「顔写真を設定してください」というプレースホルダーが表示されています。

1. 左メニュー → **「固定ページ」** → **「固定ページ一覧」**
2. トップページ（フロントページ）を編集
3. PROFILE セクションを見つける
4. 「顔写真を設定してください」のテキスト or 画像ブロックをクリック
5. **「メディアライブラリ」** から顔写真をアップロード・挿入
6. **「更新」** をクリック

> **おすすめ写真：** スーツ着用の正面写真。背景はシンプルに。サイズは 400×400px 以上推奨。

---

## ④ リンク切れを修正する

以下のリンクが壊れています。トップページの各サービスの「サービス詳細・料金を見る →」リンクを修正します。

1. トップページを編集
2. 以下のリンクを検索して修正：

|--------------------------|-------------|
| `https://keen-akune-3176.pupu.jp/mahjong/` | `https://keen-akune-3176.pupu.jp/wordpress/麻雀店営業許可/` |
| `https://keen-akune-3176.pupu.jp/inheritance/` | `https://keen-akune-3176.pupu.jp/wordpress/相続手続き/` |

| `https://keen-akune-3176.pupu.jp/about/` | `https://keen-akune-3176.pupu.jp/wordpress/事務所概要/` |

> **ヒント：** WordPressの設定でパーマリンクを変更するか、各ページのスラッグを英語に変更する方法もあります。

### パーマリンク（URL）を綺麗にする方法

各固定ページの編集画面で：
1. 右パネル → **「URL」** or **「パーマリンク」**
2. スラッグを以下に変更：

| ページ名 | 推奨スラッグ |
|---------|-------------|
| 麻雀店営業許可 | `mahjong` |
| 相続手続き | `inheritance` |
| 車庫証明 | `garage` |
| 事務所概要 | `about` |
| お問い合わせ | `contact` |

## ⑤ LINEリンクを設定する

現在、「LINEで相談する」ボタンがトップページに戻るだけになっています。

1. LINE公式アカウントの管理画面を開く
2. **「友だちを増やす」** → **「友だち追加URL」** をコピー
   - 通常 `https://lin.ee/XXXXXXX` の形式
3. WordPress管理画面に戻り、以下のページを編集：
   - トップページ
   - 麻雀店営業許可ページ
   - 相続手続きページ
   - 車庫証明ページ
4. 「💬 LINEで相談する」のリンク先を全て友だち追加URLに変更
5. 各ページで **「更新」**

## ⑥ 電話番号を実際の番号に変更する

1. 全ページの `0586-XX-XXXX` を実際の電話番号に置換
2. 対象ページ：
   - トップページ
   - 麻雀店営業許可
   - 相続手続き
   - 車庫証明
3. `tel:0586XXXXXXXX` のリンク先も実際の番号に変更
   - 例：電話番号が `0586-12-3456` なら `tel:0586123456`

- □ 各サービスの「詳細を見る」リンクが正しいページに飛ぶ
- □ 「LINEで相談する」ボタンがLINE友だち追加に飛ぶ
- □ 電話番号が実際の番号になっている
