### タイトル
車庫証明の取り方を徹底解説！必要書類・費用・期間まとめ【愛知県一宮市】

### カテゴリ

### 本文

車を購入したとき、引っ越しをしたとき、名義変更をするとき——「車庫証明」が必要になります。

でも、「車庫証明って何？」「どうやって取るの？」とお調べの方も多いのではないでしょうか。

この記事では、行政書士の立場から車庫証明の取り方をわかりやすく解説いたします。

---

#### 車庫証明とは？

車庫証明（正式名称：自動車保管場所証明書）は、**自動車の保管場所が確保されていることを証明する書類**です。

普通自動車を登録する際、管轄の警察署から交付を受ける必要があります。

#### こんなときに必要です

- ✅ 新車を購入するとき
- ✅ 中古車を購入するとき（名義変更）
- ✅ 引っ越しで住所が変わったとき
- ✅ ナンバープレートを変更するとき

> **注意：** 軽自動車の場合は「届出」のみで、証明書の交付はありません（一部地域を除く）。

#### 必要書類

| 書類名 | 入手先 | 注意点 |
|--------|--------|--------|
| 自動車保管場所証明申請書 | 警察署窓口 or ダウンロード | 正副2通 |
| 保管場所標章交付申請書 | 警察署窓口 or ダウンロード | 正副2通 |
| 保管場所の所在図・配置図 | 自分で作成 | Googleマップを活用 |
| 保管場所使用権原疎明書面（自認書） | 自分の土地の場合 | 本人が署名・押印 |
| 保管場所使用承諾証明書 | 駐車場を借りている場合 | 大家さん or 管理会社に依頼 |
| 使用の本拠の位置が確認できるもの | — | 住民票・公共料金の請求書など |

#### 費用

| 項目 | 金額 |
|------|------|
| 証明申請手数料 | 2,000円 |
| 標章交付手数料 | 300円 |
| **合計** | **2,300円** |

> ※ 愛知県の場合の金額です。都道府県により若干異なります。

#### 申請から交付までの期間

**通常3〜7営業日**です。

警察署に2回行く必要があります：
1. **1回目：** 申請書類の提出
2. **2回目：** 証明書の受取

どちらも**平日の窓口時間内**（通常 8:30〜17:15）に行く必要があります。

#### よくある失敗・注意点

1. **住所と車検証の住所が違う** → 住民票が必要
2. **使用承諾書がもらえない** → 賃貸契約書で代用できる場合あり
3. **保管場所と自宅が2km以上離れている** → 原則として申請不可
4. **配置図に寸法を書き忘れる** → 車のサイズと駐車スペースのサイズを記載

#### 行政書士に依頼するメリット

「平日に2回も警察署に行けない…」という方は、行政書士への依頼がおすすめです。

- ⏰ 警察署への申請・受取を代行
- 📋 書類の不備を防止（再提出の手間なし）
- 🚗 一宮市内なら **8,800円〜**（税込）

当事務所では、ディーラー様からのまとめ依頼も承っております。お気軽にご相談ください。

## 記事2: 麻雀店開業

### タイトル
麻雀店を開業するには？風営法の許可申請を行政書士が解説

### カテゴリ
麻雀店営業許可

### メタディスクリプション
麻雀店の開業に必要な風営法の許可申請について、麻雀プロの行政書士が解説。物件選び・必要書類・費用・審査期間など、開業までの流れをまとめました。

### 本文

「麻雀店を開きたい！」——でも、どんな許可が必要で、何から始めればいいか分からない方も多いのではないでしょうか。

麻雀プロでありWROTL2024世界王者の行政書士・吉村悠佑が、麻雀店開業の流れを解説します。

---

#### 麻雀店に必要な許可

麻雀店の営業には、**風俗営業等の規制及び業務の適正化等に関する法律（風営法）**に基づく許可が必要です。

具体的には、\*\*第4号営業（麻雀屋）\*\*の許可を取得します。

#### 許可を取得するための要件

##### 1. 人的要件（申請者の資格）

以下に該当する方は許可を受けられません：

- 破産手続開始の決定を受けて復権を得ない者
- 禁固以上の刑に処せられ、その執行を終わり5年を経過しない者
- 風営法違反で許可を取り消され、5年を経過しない者
- 暴力団員

##### 2. 場所的要件（物件の立地）

保護対象施設（学校・病院・図書館等）からの距離制限があります。

| 地域 | 距離制限 |
|------|---------|
| 商業地域 | 制限なし or 緩和されることが多い |
| その他の地域 | 保護対象施設から概ね100m以上 |

> ⚠️ **物件選びが最重要！** 物件を契約する前に、許可が取得可能かどうかを確認してください。

##### 3. 構造・設備要件

- 客室の面積：1室あたり 9.5㎡ 以上
- 客室内部を見通すことができる構造であること
- 照度：10ルクス以上
- 騒音・振動が条例で定める数値以下であること

#### 申請の流れ

1. **物件の確認** — 立地要件を満たすか事前調査
2. **必要書類の準備** — 申請書・図面・住民票等の収集
3. **警察署への申請** — 管轄の警察署に書類を提出
4. **現地調査** — 警察署の担当者が店舗を確認
5. **許可証の交付** — 申請から約55日後

#### 費用

| 項目 | 金額 |
|------|------|
| 警察署への申請手数料（証紙代） | 24,000円 |
| 行政書士報酬（当事務所） | 165,000円〜（税込） |

#### 麻雀プロの行政書士に依頼するメリット

一般の行政書士は書類の作成はできますが、**実際の麻雀店運営を知りません**。

当事務所の強み：
- 🀄 麻雀プロとして業界の内側を知っている
- 🏆 WROTL2024世界王者の実績
- 🏪 物件選びから開業後の運営まで一貫サポート
- 📋 図面作成込みのワンストップサービス

## 記事3: 相続

### タイトル
相続手続きの流れと期限を解説｜何から始める？行政書士が教えます

### カテゴリ
相続手続き

### メタディスクリプション
家族が亡くなった後の相続手続き、何から始めればいいか行政書士が解説。期限のある手続き・必要書類・費用の目安をまとめました。初回相談無料。

### 本文

大切なご家族が亡くなられたとき、悲しみの中で「相続手続き」を進めなければなりません。

「何から手をつければいいのか分からない」——そう感じている方のために、全体の流れと期限をまとめました。

---

#### 相続手続きの全体像とスケジュール

| 期限 | 手続き | 内容 |
|------|--------|------|
| **7日以内** | 死亡届の提出 | 市区町村役場に届出 |
| **14日以内** | 年金受給停止の届出 | 年金事務所に届出 |
| **3ヶ月以内** | 相続放棄（する場合） | 家庭裁判所に申述 |
| **4ヶ月以内** | 準確定申告 | 亡くなった方の確定申告 |
| **10ヶ月以内** | 相続税の申告・納付 | 税務署に申告（※対象の場合） |
| 期限なし | 遺産分割協議 | 相続人全員で遺産の分け方を決める |
| 期限なし | 名義変更 | 不動産・預貯金・車の名義変更 |

> ⚠️ **相続放棄には3ヶ月の期限があります。** 借金がある場合は急いでください。

#### 行政書士ができること・できないこと

| ○ 行政書士ができる | × 行政書士ができない |
|-------------------|---------------------|
| 戸籍謄本の収集 | 不動産の名義変更（→ 司法書士） |
| 相続関係説明図の作成 | 相続税の申告（→ 税理士） |
| 遺産分割協議書の作成 | 相続人間の紛争解決（→ 弁護士） |
| 財産調査・財産目録の作成 | |
| 遺言書の作成サポート | |
| 各種届出の代行 | |

> 司法書士・税理士・弁護士が必要な場合は、提携先をご紹介いたします。

#### 相続に必要な書類

- 被相続人の出生から死亡までの戸籍謄本
- 相続人全員の戸籍謄本
- 相続人全員の印鑑登録証明書
- 被相続人の住民票の除票
- 固定資産評価証明書（不動産がある場合）
- 金融機関の残高証明書

> **戸籍の収集は大変です。** 複数の自治体にまたがることも多く、郵送請求が必要な場合もあります。当事務所で代行可能です。

#### 費用の目安（当事務所）

| 業務内容 | 報酬額（税込） |
|---------|---------------|
| 相続人調査・相続関係図 | 33,000円〜 |
| 遺産分割協議書作成 | 33,000円〜 |
| 相続財産調査・財産目録 | 33,000円〜 |
| 遺言書作成サポート | 44,000円〜 |

私自身、母と叔母が祖父の相続をきっかけに不仲になるのを見てきました。

相続は財産の問題だけではありません。**家族の関係が壊れないように、早い段階で専門家に相談する**ことが大切です。

### 本文

「行政書士に頼みたいけど、たくさんいてどこに頼めばいいかわからない…」

そんな方のために、行政書士の選び方5つのポイントをお伝えします。

---

#### ポイント1: 得意分野を確認する

行政書士が扱える業務は非常に幅広いですが、一人の行政書士が全ての業務に精通しているわけではありません。

**自分が依頼したい業務を専門的に扱っているか**を確認しましょう。

ホームページやブログで情報発信しているかも判断材料です。

#### ポイント2: 料金が明瞭かどうか

- ✅ ホームページに料金表が掲載されている
- ✅ 事前に見積りを出してくれる
- ✅ 追加料金の条件が明示されている

> ❌ 「お問い合わせください」としか書いていない場合は注意。

#### ポイント3: 初回相談が無料かどうか

初回相談無料の事務所を選びましょう。依頼するかどうか迷っている段階でも、気軽に相談できます。

#### ポイント4: 対応エリアを確認する

行政書士は全国どこでも業務ができますが、**警察署や役所への提出が必要な業務**は、事務所の所在地から近い方がスムーズです。

#### ポイント5: 人柄・相性を大事にする

行政書士への依頼は、少なくとも数週間〜数ヶ月のお付き合いになります。

- 話しやすいか
- 専門用語を使わず説明してくれるか
- レスポンスが早いか

**実際に会って（またはオンラインで）話してみることをおすすめします。**

## 記事5: 遺言書の書き方

### タイトル
自筆証書遺言の書き方ガイド｜注意点・無効になるケースを解説

### カテゴリ
相続手続き

### メタディスクリプション
自筆証書遺言の正しい書き方を行政書士が解説。無効になるケース・必須要件・公正証書との違い・保管制度についてわかりやすくまとめました。

### 本文

「遺言書を書いておきたいけど、書き方がわからない」
「せっかく書いても無効になったら意味がない…」

この記事では、自筆証書遺言の正しい書き方と注意点を解説します。

---

#### 遺言書の種類

| 種類 | 特徴 | 費用の目安 |
|------|------|-----------|
| **自筆証書遺言** | 自分で手書きする。手軽だが要件を満たさないと無効に | 無料〜 |
| **公正証書遺言** | 公証人が作成。確実だがコストがかかる | 公証人手数料＋行政書士報酬 |
| 秘密証書遺言 | 実務ではほとんど使われない | — |

#### 自筆証書遺言の必須要件（これを満たさないと無効！）

1. **全文を自筆で書く**（パソコン・代筆は不可）
   - ※ 財産目録のみパソコン作成OK（2019年改正）
2. **日付を正確に記載する**（「令和6年2月吉日」→ ❌ 無効！）
3. **氏名を自書する**
4. **押印する**（実印でなくても可。ただし実印推奨）

#### 遺言書の書き方テンプレート

```
              遺 言 書

 遺言者 吉村太郎は、以下のとおり遺言する。

一、遺言者は、下記の不動産を、妻 吉村花子（昭和○年○月○日生）に
    相続させる。

    所  在  愛知県一宮市○○町○丁目
    地  番  ○番○
    地  目  宅地
    地  積  ○○.○○平方メートル

二、遺言者は、○○銀行 ○○支店 普通口座 口座番号○○○○の預金を、
    長男 吉村一郎（平成○年○月○日生）に相続させる。

三、上記以外の一切の財産は、妻 吉村花子に相続させる。

四、遺言執行者として、下記の者を指定する。
    住  所  愛知県一宮市○○
    氏  名  ○○○○
    生年月日  ○○年○月○日

  令和○年○月○日

        住所  愛知県一宮市○○
        遺言者  吉村 太郎  ㊞
```

#### よくある無効パターン

| ❌ 無効になるケース | 理由 |
|-------------------|------|
| パソコンで印刷した | 全文自筆が必要 |
| 「2月吉日」と書いた | 日付が特定できない |
| 押印がない | 必須要件 |
| 夫婦で一通にまとめた | 共同遺言は禁止 |
| 修正の仕方が不適切 | 加除訂正のルールがある |

#### 法務局の自筆証書遺言書保管制度

2020年7月から、**法務局で自筆証書遺言を保管してもらえる制度**が始まりました。

メリット：
- 紛失・改ざんの心配がない
- 相続開始時に家庭裁判所の検認が不要
- 保管料は1通あたり3,900円と低コスト

#### 不安なら専門家に相談を

遺言書は、一文字の間違いで無効になることもあります。

当事務所では、遺言書の原案作成・法的有効性のチェックを承っております。

- 自筆証書遺言サポート：**44,000円〜**（税込）
- 公正証書遺言サポート：**88,000円〜**（税込・公証人手数料別途）
