# 事務所用Googleアカウントへの完全移行手順

ダッシュボードのデータベース（スプレッドシート）とファイルの保存先を、個人のGoogleアカウントから「事務所用のGoogleアカウント」へお引っ越しする手順です。
以下の手順を順番に行うことで、安全に移行が完了します。

## 1. スプレッドシートの移行（個人アカウントでの操作）

1. 現在お使いの個人用Googleアカウントで、ダッシュボード用の**スプレッドシート**を開きます。
2. 右上の **「共有」** ボタンを押します。
3. 共有相手に **「事務所用のGoogleアカウント（メールアドレス）」** を入力し、権限を **「編集者」** にして送信します。
4. 一度、個人のGoogleアカウントからはログアウトします。

## 2. コピーの作成と連携（事務所用アカウントでの操作）

1. **事務所用のGoogleアカウント**でログインし直します。
2. Googleドライブの「共有アイテム」を開き、先ほど共有されたスプレッドシートを開きます。
3. 左上のメニューから **「ファイル」 ＞ 「コピーを作成」** をクリックします。
   *※コピーすることで、所有者が完全に「事務所用アカウント」になります。*
4. コピーして新しくできたスプレッドシートの画面で、上部メニューの **「拡張機能」 ＞ 「Apps Script」** を開きます。
5. （プログラムはそのままコピーされていますので）右上の青い **「デプロイ」** ボタン ＞ **「新しいデプロイ」** をクリックします。
6. 設定を以下のようにして「デプロイ」を押します。
   - 種類の選択: ウェブアプリ（歯車マークから選択）
   - アクセスできるユーザー: **「全員」**
   - 実行するユーザー: **「自分」**
7. 画面に **「ウェブアプリのURL」** が表示されるので、コピーします。

## 3. ダッシュボードへの新しいURLの登録

1. 普段お使いの [行政書士ダッシュボード](https://gyosei-dashboard.yuusuke89sb.workers.dev/) を開きます。
2. 左下のメニューから **「⚙️ 設定」** （またはスプレッドシート連携設定）を開きます。
3. 「GAS Web App URL」の入力欄に、**先ほどコピーした新しいURL** を貼り付けて、保存ボタンを押します。
4. 念のため「🔍 接続テスト」を押して、データが読み込めるか確認します。

---
以上で移行は完了です！
これ以降、ダッシュボードで新規案件を登録したり書類を作成したりすると、すべて **「事務所用のGoogleドライブ」** に自動フォルダが作られ、そこに保存されていきます。

> **※注意**
> これまで個人ドライブに作られた過去の案件フォルダは、自動では移動しません。必要であれば、個人ドライブの「行政書士事務所」フォルダを手動でダウンロードし、事務所用ドライブにアップロードし直してください。
