## 分析のポイント

| 指標 | 見るべきこと |
|------|-------------|
| NPS（Q8） | 9-10=推奨者、7-8=中立者、0-6=批判者。推奨者% − 批判者% = NPSスコア |
| 総合満足度（Q6） | 平均4.0以上を目標 |
| リピート意向（Q7） | 「ぜひ」+「機会があれば」が80%以上を目標 |
| 自由記述（Q9-10） | 具体的な改善ポイントを拾い上げる |
