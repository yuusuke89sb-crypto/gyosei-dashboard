# Google Apps Script デプロイ手順ガイド

## 概要

ダッシュボードの `master_sheets.gs` をGoogle Apps Scriptにデプロイし、スプレッドシートとの双方向同期を有効化する手順です。

---

## 手順 1: スプレッドシートの作成

1. [Google Sheets](https://sheets.google.com) を開く
2. **「空白のスプレッドシート」** をクリックして新規作成
3. ファイル名を **「行政書士事務所 マスタデータ」** に変更

## 手順 2: Apps Script を開く

1. メニューから **拡張機能 → Apps Script** をクリック
2. 新しいタブで Apps Script エディタが開く

## 手順 3: コードを貼り付け

1. エディタに最初から表示されている `function myFunction()` を **全て削除**
2. `gas/master_sheets.gs` のファイルを開き、内容を **全てコピー**
3. Apps Script エディタに貼り付け
4. **Ctrl + S** で保存（プロジェクト名は「行政書士マスタ管理」等に設定）

## 手順 4: 初期セットアップの実行

1. Apps Script エディタ上部の関数選択で **`initialSetup`** を選択
2. **「▶ 実行」** ボタンをクリック
3. 初回実行時に **権限の承認** が求められます
   - 「このアプリは確認されていません」→ **「詳細」** をクリック
   - **「（プロジェクト名）（安全ではないページ）に移動」** をクリック
   - 表示される権限を **「許可」** する
4. スプレッドシートに戻ると、以下の3シートが作成されています：
   - **顧客マスタ** — ヘッダー・入力規則・条件付き書式付き
   - **担当者マスタ** — 同上
   - **操作ログ** — 変更履歴の自動記録用

## 手順 5: Web App としてデプロイ

1. Apps Script エディタに戻る
2. 右上の **「デプロイ」** → **「新しいデプロイ」** をクリック
3. 歯車アイコン横の **「種類の選択」** → **「ウェブアプリ」** を選択
4. 以下を設定：
   - **説明**: `マスタデータ同期API`
   - **次のユーザーとして実行**: `自分`
   - **アクセスできるユーザー**: `自分のみ`（セキュリティ上推奨）
5. **「デプロイ」** をクリック
6. 表示される **Web App URL** をコピー
   - `https://script.google.com/macros/s/XXXX.../exec` の形式

> [!IMPORTANT]
> この URL は **絶対に外部に公開しないでください**。この URL を知っている人はデータにアクセスできます。

## 手順 6: ダッシュボードに URL を設定

1. ダッシュボード（`gyosei-dashboard/index.html`）を開く
2. サイドバー下部の **「⚙️ 設定」** ボタンをクリック
3. **「GAS Web App URL」** 欄にコピーした URL を貼り付け
4. **「🔍 接続テスト」** をクリックして接続確認
5. 「✅ 接続成功！ 顧客: 0件 / 担当者: 0件」が表示されればOK
6. **「💾 保存」** をクリック

## 手順 7: 同期の確認

1. ダッシュボードで顧客を追加 → スプレッドシートに反映されることを確認
2. サイドバーの **「🔄 同期」** ボタンでスプレッドシートからデータを取得

---

## トラブルシューティング

| 問題 | 対処法 |
|------|--------|
| 接続テストで「404」 | Web App URL が正しいか確認。`/exec` で終わっているか |
| 接続テストで「403」 | アクセス権限の設定を確認。自分のGoogleアカウントでログインしているか |
| データが反映されない | ブラウザのコンソールでエラーを確認。GASのログ（実行ログ）も確認 |
| コードを変更した | 変更後は **「デプロイ」→「デプロイを管理」→「新しいバージョン」** で再デプロイが必要 |
